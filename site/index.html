The tool

Crosscheck is a plugin for Claude Code. It checks what an AI coding agent claims about code. It does this with Lean and Dafny proofs, generated tests against a reference model, reproduction scripts, and a checker for the data contracts in Python projects.

An AI agent may draft the code, the specifications and the proofs. No result rests on the agent’s judgement. Only deterministic checks and decisions a named person made count as evidence.

Each study marks every piece of evidence with one of five strengths: Proved, Tested, Decided by Harry, Assumed or Not yet reached. Where a check does not yet reach some code, the study says so, and names what blocks it.

Install

In Claude Code:

claude plugin marketplace add nicholls-inc/claude-code-marketplace
claude plugin install crosscheck@nicholls

The proof tools run in Docker. See the repository (opens in a new tab) for the prerequisites.
