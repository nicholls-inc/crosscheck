# Crosscheck landing page: mockup-first shape

## Problem
Crosscheck needs a landing page that explains its verification mechanism and gives developers concrete evidence from library case studies.

## Proposed outcome
Image mockups and a reviewable design brief only. The primary CTA is install the Claude Code plugin. The first case study is https://github.com/nicholls-inc/crosscheck/pull/144.

## Users and systems
Prospective Crosscheck users evaluating the plugin. Developer audience is inferred from the existing product and install action. No application or verification engine changes.

## Constraints
Preserve the distinction between model proofs, differential tests, and implementation guarantees. No invented customers, adoption claims, additional case studies, or whole-library proof claims. No website implementation, deployment, or stack selection in this phase. Visual direction remains subject to user selection.

## Open questions
Visual world and composition are to be selected from the mockups. Additional case studies require evidence supplied later.

## Replacement requested
The user rejected all initial mockups on 2026-10-27 as gaudy and inconsistent with Crosscheck. Start from scratch using docs/VISION.md and https://www.are.na/harry-nicholls/crosscheck.
