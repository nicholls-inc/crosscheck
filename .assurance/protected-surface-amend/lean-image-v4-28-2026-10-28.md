### Rationale

The trigger is PR #145, which moves the Crosscheck Lean image from Lean and Mathlib v4.10.0 to v4.28.0. The image could not build the OCPP 1.6 model in PR #144, because the model uses `List.Pairwise` from Lean core, and v4.10.0's core does not have it. With v4.28.0, `/lean-spec`'s instruction to `import Mathlib.Data.Nat.Defs` fails, because that module no longer exists.

The skill tables were checked on 2026-10-28. Each module was compiled in both images with `docker run --rm --network none -v <dir>:/work <image> check /work/program.lean`, which is what `lean_check` runs. Five more imports named in the skills fail on both images:

- `Mathlib.Analysis.SpecialFunctions.Basic`
- `Mathlib.Data.Array.Basic`
- `Mathlib.Data.HashMap.Basic`
- `Mathlib.Data.Json`
- `Mathlib.Tactic.DeriveDecidableEq`

So a model that follows those rows fails `lean_check` today, whichever image it uses. Every replacement passes in the v4.28.0 image. The plan lists each result: `intent/2026-10-27-lean-image-v4-28-plan.md`.

The maintainer asked on 2026-10-28 for everything #145 needs to be prepared for approval.
